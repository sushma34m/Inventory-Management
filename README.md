# Inventory-Management
## Abstarct 
Perishable products in retail stores may remain unsold as they approach expiry, causing financial loss and product waste. This project proposes an AI-Powered Smart Inventory Recovery and Optimization System for SHAYA, a retail company with multiple branches. The system uses branch sales history, inventory, expiry dates, demand forecasts, transportation cost, branch capacity and supplier-return conditions to identify at-risk stock. It then evaluates recovery options such as manufacturer return, inter-branch transfer, discounting, retention and disposal. Demand forecasting, uncertainty estimation and scenario simulation are used to test decisions under changing conditions. The expected outcome is an explainable recommendation that reduces expiry losses and unnecessary recovery costs while improving inventory utilization across branches.
